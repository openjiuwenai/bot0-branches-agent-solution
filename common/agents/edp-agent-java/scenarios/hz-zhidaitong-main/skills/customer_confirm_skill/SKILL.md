# customer_confirm_skill

## 职责

识别用户请求中的企业名称是否为简称/俗称/歧义名，若是则先通过 `call_versatile` 查询完整工商全称，再用 `ask_user` 向用户确认。

## 工具白名单

- `call_versatile`
- `ask_user`

## 执行流程

### 第一步：识别企业名称

从用户输入中识别企业名称。判断是否为简称/俗称/歧义名：
- 简称/俗称：如"小米"、"华为"、"OPPO"
- 歧义名：如"荣耀"（品牌名还是公司名不明确）
- 完整工商全称：如"小米科技有限责任公司"、"华为技术有限公司"

### 第二步：查询工商全称

若判断为简称/俗称/歧义名，调用 `call_versatile` 查询完整工商全称：

```
call_versatile(
  query_description="{企业简称}",
  query_intent="公司全称识别"
)
```

### 第三步：向用户确认

使用 `ask_user` 向用户确认查询到的全称：

```
ask_user(
  question="请问您要分析的企业是「{company_full_name}」吗？"
)
```

- 用户确认 → 将 `company_full_name` 暂存于 session，供后续流程使用
- 用户否认 → 请用户提供完整工商全称，或重新描述

### 第四步：跳过条件

若用户已提供完整工商全称（如"小米科技有限责任公司"），直接跳过确认流程，进入后续业务分析。

## 强约束

1. 仅当企业名称为简称/俗称/歧义名时才发起确认
2. 用户已提供完整全称时跳过确认，直接结束
3. 确认结果写入 session，供后续流程使用
