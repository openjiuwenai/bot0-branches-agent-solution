# 行为和证据边界

Scenario 只从材料提取会影响最终 Skill 行为的事实和冲突。

## 必须保留的边界

- **触发边界**：哪些任务应使用该 Skill，哪些相邻任务不应使用。
- **输入输出边界**：必需输入、可选输入、输出内容和格式。
- **执行边界**：哪些步骤可自动完成，哪些依赖凭据、网络、内网或人工确认。
- **证据边界**：材料明确了什么，哪些信息缺失或互相冲突。

外部系统被登录、验证码、权限、内网、DNS 或超时阻断时，只记录前置条件和
降级处理。不要声称该外部能力已验证、低风险或一定可用，也不要为当前 Session
生成平台探测脚本、截图要求或验证报告。

## 写包边界

`generated-skill/` 只包含另一个 Agent 复用该能力时真正需要的内容：

- `SKILL.md`；
- 可选的 `references/`、`scripts/`、`fixtures/`、`assets/`；
- 可选的 `agents/openai.yaml` 和运行依赖清单。

上传材料、Scenario 投影、当前会话输出和平台状态都不属于导出包。对材料无法证明
的业务结论，在 Scenario conflict 或最终 Skill 的前置条件/复核边界中如实表达。
