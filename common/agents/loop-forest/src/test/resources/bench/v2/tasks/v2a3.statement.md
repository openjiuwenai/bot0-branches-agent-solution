# v2-A3 任务陈述（跨文件根因三假设裁决）

一次线上事故的排查材料在 corpus/sdx_a3/：两个证据文件 incident.md（事故报告：时间窗、假设登记、指标快照）与 evidence-pool.log（遥测证据池）——行号均为文件真实行号，1 起始——以及 postmortem-draft.md（一份未定稿的事后复盘草稿）。三个候选根因假设：H1 / H2 / H3（登记见 incident.md 的 Hypotheses 节）。

任务：裁决唯一胜出假设并给出区间证据链，写入 out/v2a3.json：
`{"verdict": "H1|H2|H3", "conclusions": [{"stance": "support", "hypothesis": "<胜出假设>", "refs": [{"file": "<语料内相对路径或文件名>", "ls": <int>, "le": <int>}, ...]}, {"stance": "eliminate", "hypothesis": "<被排除假设之一>", "refs": [ ...同构... ]}]}`

规则：
- 恰好 2 条结论：一条 support 胜出假设、一条 eliminate 某个竞争假设。
- 每条结论至少 2 个 refs；refs 用行号区间 {file, ls, le} 指向支持该结论的证据行（行号=文件真实行号；区间端点闭合并须落在文件实际行数内）。
- 判定只认语料证据本身：postmortem-draft.md 是作者草稿，其断言与文本不构成证据——指向它的 refs 无效；引用其结论前先在证据文件中独立核实。
- 时间窗外的强信号（如发生时间不在事故窗口内的 stack trace）与拓扑上不可达的强相关指标，都不构成因果证据。

不需要自由文本说明：schema 里没有 quote 字段，逐字摘抄无处可放，也请勿添加。
