# v2-A7 任务陈述（单文件短链重建）

参数 cache_size_mb 的取值历史集中在一个事件文件里：corpus/sr_a7/tuning-log.jsonl（多参数事件流，含若干干扰参数）；值与时间戳的勘误在 corpus/sr_a7/errata.md。

任务：重建该参数的生效取值序列，写入 out/v2a7.json：
`{"param": "cache_size_mb", "final_value": <值>, "chain_len": <int>, "value_series": [<按生效顺序排列的取值序列>], "confidence": <1-5 整数>, "assumptions": "<一段话>", "provenance_summary": "<一段话>"}`

规则：
- 只追踪 cache_size_mb 的事件；文件内其它参数（如 pool_min / pool_decay）与本题无关。
- errata 的值修正与时间戳修正都要应用：以修正后的值与次序为准重建序列。
- value_series 为逐位有序序列；chain_len 与 value_series 等长；final_value 为末位生效值。

另外：在 "confidence" 里给 1-5 的置信整数，用一段话在 "assumptions" 里说明你依赖的假设，并在 "provenance_summary" 里说明每个关键取值的出处依据。
