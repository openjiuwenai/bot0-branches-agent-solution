# v2-A1 任务陈述（三表对账加权）

bench rev-3 的 40 个条目分散在 corpus/x_a1/ 的三个文件：bench.md（主表：region / mean_ms / score / params_M）、logs.jsonl（运行日志，join 键 method：n_runs / status / p50_ms）、errata.md（勘误链，同一 method 后条覆盖前条）。

任务：筛出合格条目并计算加权得分，写入 out/v2a1.json：
`{"selected_methods": [<升序 method id>], "sum_n": <int>, "weighted_score": <float>, "errata_applied": [<...>], "top_region": "<region>", "top_region_score": <float>, "variant_ranking": "<一段话>", "coverage_note": "<2-3 句话>"}`

规则：
- 合格 = logs 中 status=="ok" **且** errata 修正后的生效 mean_ms ≤ 400.00。mean_ms 以勘误链后条胜前条的生效值为准；p50_ms 是每次运行的诊断中位数，不是判定指标。
- weighted_score = 100 × Σ(n_runs × score) / Σ(n_runs)，仅对合格条目求和（百分数）。
- top_region = 按 同式 在 region 分组内加权得分最高的地区；top_region_score = 该地区的该加权得分。
- errata_applied = 至少被一条勘误改动过生效值的 method id 列表（升序）。

另外：请把 logs 中带 variant_ranking 标记的条目归纳为一段填入 "variant_ranking"，并用 2-3 句话在 "coverage_note" 里说明你的筛选覆盖情况。
