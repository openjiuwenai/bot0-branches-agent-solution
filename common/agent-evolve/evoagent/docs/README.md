# 什么是智能体自进化引擎（EvoAgent）

智能体自进化引擎（EvoAgent）提供「数据回流 → 轨迹评估 → 优化引擎」的闭环能力，帮助用户基于Agent真实运行轨迹，持续优化Prompt与Skill等对象，实现Agent自主演进。

EvoAgent 面向 Agent 能力持续优化场景，核心能力包括：

**数据回流**：采集 Agent 运行轨迹，完成清洗与结构化归一，为评估与优化提供高质量输入。

**轨迹评估**：提供指标评估器与 LLM 评估器，对轨迹质量进行判定与评分，定位 Skill / Prompt 优化点并输出评估结果。

**优化引擎**：基于评估结果执行 Prompt 优化与 Skill 优化，将优化结果回合到目标 Agent，形成可验证的演进闭环。

**自进化 Agent**：通过agent方式实现智能体轨迹评估、Skill优化全流程。

# 🔧 主要功能



## 数据回流

- ✅ 轨迹采集：从 Agent 运行日志 / Agent 上报OpenTelemetry格式数据 中回流结构化轨迹
- ✅ 轨迹清洗：归一化为标准轨迹格式，支持场景级清洗扩展
- ✅ 轨迹增强：动态规划场景下，支持轨迹 span 节点与 skill / agent.md 内联映射



## 轨迹评估

- ✅ 指标评估器：支持F1、精确率、关键词匹配、语义相似度等指标评估
- ✅ LLM 评估器：任务完成度、轨迹质量、安全性等多维评分
- ✅ Agent 评估器：支持 Agent as a Judge 评估器，支持路径识别与链路归因
- ✅ 优化建议：支持 Skill 归因，输出可执行的优化建议
- ✅ 批量评估：支持数据集级离线评估与结果聚合



## 优化引擎

- ✅ Prompt 优化：基于评估反馈自动迭代优化提示词，支持 SkillOpt / GEPA 算法
- ✅ Skill 优化：通过反思 → 聚合 → 选择 → 应用优化Skill文档
- ✅ 验证门控：训练集优化 + 验证集验收，输出优化报告



## 自进化 Agent

- ✅ 业务agent自进化：通过智能体原生能力实现数据集导入→轨迹评估→策略优化→沙箱 Rollout 验证全流程



## 南北向对接

- ✅ 北向对接 Skillhub：支持通过 Skillhub 对接实现 Skill 版本的离线更新迭代

# 🔄 运行流程

```
Agent 运行轨迹
      │
      ▼
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  数据回流     │ ──▶ │  轨迹评估     │ ──▶ │  优化引擎     │
│ 采集/清洗/增强│     │指标/LLM/Agent│     │Prompt/Skill  │
└──────────────┘     └──────────────┘     └──────────────┘
                                               │
                                               ▼
                                        回写目标 Agent
                                        输出优化报告
                                               │
                                               ▼
                                        ┌──────────────┐
                                        │ 对接    │
                                        │ Skillhub 离线│
                                        │ 版本更新迭代  │
                                        └──────────────┘
```
