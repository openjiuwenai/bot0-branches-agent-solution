# 什么是智能体自进化引擎（EvoAgent）

智能体自进化引擎（EvoAgent）提供「数据回流 → 轨迹评估 → 优化引擎」的闭环能力，帮助用户基于 Agent真实运行轨迹，持续优化Prompt与Skill等对象，实现Agent自主演进。

EvoAgent 面向 Agent 能力持续优化场景，核心能力包括：

**数据回流**：采集 Agent 运行轨迹，完成清洗与结构化归一，为评估与优化提供高质量输入。

**轨迹评估**：提供指标评估器与 LLM 评估器，对轨迹质量进行判定与评分，定位 Skill / Prompt 优化点并输出评估结果。

**优化引擎**：基于评估结果执行 Prompt 优化与 Skill 优化，将改进回写到目标 Agent，形成可验证的演进闭环。

**自进化 Agent**：提供 EDPAgent 等离线自进化场景能力，一站式编排回流、评估与优化流程。

# 🔧 主要功能



## 数据回流

- ✅ 轨迹采集：从 Agent 运行日志 / Adapter 回流结构化轨迹
- ✅ 轨迹清洗：归一化为标准轨迹格式，支持场景级清洗扩展
- ✅ 轨迹过滤：工具失败、用户反馈等确定性信号筛除



## 轨迹评估

- ✅ 指标评估器：Exact Match、Contains、Regex、数值容差等确定性指标
- ✅ LLM 评估器：任务完成度、轨迹质量、安全性等多维评分
- ✅ 优化点定位：支持 Skill 归因，输出可执行的优化建议
- ✅ 批量评估：支持数据集级离线评估与结果聚合



## 优化引擎

- ✅ Prompt 优化：基于评估反馈自动迭代优化提示词 / 变体
- ✅ Skill 优化：ReflACT 管线（反思 → 聚合 → 选择 → 应用）优化 Skill 文档
- ✅ 验证门控：训练集优化 + 验证集验收，输出优化报告



## 自进化 Agent

- ✅ EDPAgent 离线自进化：远程 Rollout + 轨迹回流 + 评估 + 优化闭环
- ✅ 场景插件化：按场景目录扩展业务 Agent（scenario.yaml + optimizer）
- ✅ CLI / API 双模式：本地编排与平台集成均可接入
- ✅ 异步任务与 SSE：优化进度实时可观测，支持取消与回滚

# 🔄 运行流程

```
Agent 运行轨迹
      │
      ▼
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  数据回流    │ ──▶ │  轨迹评估    │ ──▶ │  优化引擎    │
│ 采集 / 清洗  │     │ 指标 / LLM  │     │ Prompt/Skill│
└─────────────┘     └─────────────┘     └─────────────┘
                                               │
                                               ▼
                                        回写目标 Agent
                                        输出优化报告
```
