# 智能体自进化引擎（EvoAgent）v0.1.0 版本更新日志

欢迎体验智能体自进化引擎（EvoAgent）v0.1.0正式发布版本。本版本提供「数据回流 → 轨迹评估 → 优化引擎」闭环能力，基于 Agent 真实运行轨迹完成质量判定，并通过优化引擎持续改进 Prompt 与 Skill，实现 Agent 自主演进。

## 全新功能

### 数据回流

- **轨迹采集**：通过 Adapter 采集 Agent 运行轨迹并结构化回流。
- **轨迹清洗**：将异构轨迹归一为标准格式，支持工具失败、用户反馈等确定性过滤。

### 轨迹评估

- **指标评估器**：提供 Exact Match、Contains、Regex、数值容差等确定性指标评估。
- **LLM 评估器**：对任务完成度、轨迹质量、安全性进行多维评分，并支持 Skill 归因。

### 优化引擎

- **Skill 优化器**：基于 ReflACT 管线自动优化 Skill 文档并回写目标 Agent。
- **Prompt 优化器**：支持 Prompt / 托管文档自动优化，含变体选优、验证门控与取消回滚。

### 自进化 Agent

- **EDPAgent 离线自进化**：一站式编排回流、评估与优化，支持场景插件化扩展。
- **CLI / API 双模式**：支持本地编排与平台集成；优化任务支持异步提交与 SSE 进度推送。
