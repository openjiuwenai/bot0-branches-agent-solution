发布日期：2026 年 8 月 30 日

欢迎体验 v0.2.0 —— 智能体自进化引擎（EvoAgent）的迭代发布版本！本版本在 v0.1.0「数据回流 → 轨迹评估 → 优化引擎」闭环能力基础上，新增轨迹增强、Agent 评估器、GEPA 优化算法适配与北向 Skillhub 对接能力，进一步覆盖动态规划场景下的轨迹归因与 Skill 版本离线迭代。


## 🚀 新特性

### 📥 数据回流

- **轨迹增强**：动态规划场景下，支持轨迹 span 节点与 skill /agent.md 内联映射，实现轨迹与 Skill / AgentRule 的细粒度对应，为归因与优化提供更精确的数据。

### 📊 轨迹评估

- **Agent 评估器**：支持 Agent as a Judge评估器，具备路径识别与链路归因能力，可对轨迹的执行路径进行判定与归因分析。

### ⚙️ 优化引擎

- **Prompt 优化器**：支持基于评估反馈自动迭代优化提示词，支持SkillOpt算法；本版本新增适配GEPA优化算法。

### 🔗 南北向对接

- **北向对接 Skillhub**：支持通过 Skillhub 对接实现 Skill 版本的离线更新迭代，便于完成 Skill 版本管理与迭代。
