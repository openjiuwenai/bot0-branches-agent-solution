# highway — 公路行业专属资产

本目录用于存放 **交通行业 Agent 解决方案** 中 **公路子行业** 的专属资产。

## 目录定位

`highway` 聚焦公路运输场景下的行业专属内容——当某些方法论、Skill、MCP 或 Agent 工具仅适用于公路子行业、不宜作为跨子行业共享资产时，存放于本目录。

典型场景包括（但不限于）：

- **公路货运**：整车、零担、专线运输的调度与履约
- **城市配送**：城配路径规划、运力匹配、末端履约
- **高速公路**：收费、服务区、路网监控与诱导
- **公路监管**：治超治载、两客一危、营运资质核查

## 与顶层目录的关系

| 目录 | 职责 |
|------|------|
| `methodology/` | 跨子行业共享的方法论与流程工具 |
| `workshop/skills/` | 跨子行业共享的精品 Skill |
| `workshop/mcp/` | 跨子行业共享的精品 MCP |
| `workshop/tools/` | 跨子行业共享的精品 Agent 工具 |
| `highway/` | **公路子行业专属资产**（本目录） |

当资产可被多个子行业复用时，应放入顶层 `methodology/` 或 `workshop/`；仅当强绑定公路场景时，才放入本目录。

## 目录约定

本目录初期以 `README.md` 作为占位。后续可按需补充以下子目录：

```
highway/
├── README.md
├── methodology/      # 可选：公路专属方法论
├── skills/           # 可选：公路专属 Skill
├── mcp/              # 可选：公路专属 MCP
└── tools/            # 可选：公路专属 Agent 工具
```

## 贡献说明

新增公路专属资产时，请确保：

1. 说明该资产为何属于公路专属、不适宜作为跨子行业共享资产
2. 遵循顶层 `methodology/` 与 `workshop/` 中的目录约定与质量要求
3. 遵循仓库 [贡献指南](../../CONTRIBUTING.md) 提交 PR
