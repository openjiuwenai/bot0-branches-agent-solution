# aviation — 航空行业专属资产

本目录用于存放 **交通行业 Agent 解决方案** 中 **航空子行业** 的专属资产。

## 目录定位

`aviation` 聚焦航空运输场景下的行业专属内容——当某些方法论、Skill、MCP 或 Agent 工具仅适用于航空子行业、不宜作为跨子行业共享资产时，存放于本目录。

典型场景包括（但不限于）：

- **航空客运**：航班排班、座位管理、登机与中转服务
- **航空货运**：舱位管理、货站作业、航空集装器（ULD）调度
- **机场运营**：机位分配、安检、地勤保障、航站楼服务
- **航空监管**：航班合规、适航、空管协同

## 与顶层目录的关系

| 目录 | 职责 |
|------|------|
| `methodology/` | 跨子行业共享的方法论与流程工具 |
| `workshop/skills/` | 跨子行业共享的精品 Skill |
| `workshop/mcp/` | 跨子行业共享的精品 MCP |
| `workshop/tools/` | 跨子行业共享的精品 Agent 工具 |
| `aviation/` | **航空子行业专属资产**（本目录） |

当资产可被多个子行业复用时，应放入顶层 `methodology/` 或 `workshop/`；仅当强绑定航空场景时，才放入本目录。

## 目录约定

本目录初期以 `README.md` 作为占位。后续可按需补充以下子目录：

```
aviation/
├── README.md
├── methodology/      # 可选：航空专属方法论
├── skills/           # 可选：航空专属 Skill
├── mcp/              # 可选：航空专属 MCP
└── tools/            # 可选：航空专属 Agent 工具
```

## 贡献说明

新增航空专属资产时，请确保：

1. 说明该资产为何属于航空专属、不适宜作为跨子行业共享资产
2. 遵循顶层 `methodology/` 与 `workshop/` 中的目录约定与质量要求
3. 遵循仓库 [贡献指南](../../CONTRIBUTING.md) 提交 PR
