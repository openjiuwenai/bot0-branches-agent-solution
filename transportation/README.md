# transportation — 交通行业 Agent 解决方案

本目录为 **agent-solution_transportation** 的核心资产区，由「跨子行业共享资产」与「子行业专属资产」两部分组成。

## 跨子行业共享资产

按能力类型划分为以下子目录，存放可被多个子行业复用的资产：

| 目录 | 说明 |
|------|------|
| [methodology/](methodology/) | 方法论与流程工具——分析框架、模板、辅助脚本等 |
| [workshop/](workshop/) | 工作坊——汇聚精品 Skill、精品 MCP 与精品 Agent 工具 |

两者协同：`methodology` 定义规范与流程，`workshop` 封装 Agent 能力、外部连接与可加载工具。

## 子行业专属资产

按交通子行业划分，仅存放强绑定该子行业、不宜跨子行业共享的资产：

| 目录 | 说明 |
|------|------|
| [highway/](highway/) | 公路行业——公路货运、城市配送、高速公路、公路监管等 |
| [aviation/](aviation/) | 航空行业——航空客运、航空货运、机场运营、航空监管等 |
| [port/](port/) | 港口行业——码头作业、集装箱管理、港口物流、港口监管等 |
| [railway/](railway/) | 铁路行业——铁路客运、铁路货运、线路与机车、铁路监管等 |

**资产归属原则**：可被多个子行业复用的资产放入顶层 `methodology/` 或 `workshop/`；仅当强绑定单一子行业时，才放入对应子行业目录。
