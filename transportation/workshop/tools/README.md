# tools — 公路 AI 精品 Agent 工具

本目录用于存放 **交通行业 Agent 解决方案** 中面向公路 AI 场景的精品 Agent 工具资产。

## 目录定位

`tools` 聚焦「公路 AI 场景下的精品 Agent 工具」——将公路运输领域的专业知识与操作能力封装为 Agent 可直接加载、调用的精品工具，用于在 Agent 运行时完成特定计算、校验或处理任务。

精品 Agent 工具应具备：

- **场景明确**：面向公路运输具体业务（如路径规划、运力匹配、载重校验、时效估算等）
- **质量可控**：经过验证的实现、清晰的输入输出契约与边界说明
- **可复用**：结构清晰，便于在不同 Agent 运行时中集成
- **即插即用**：与 Skill、MCP 解耦，可被按需加载组合

典型能力包括（但不限于）：

- **计算工具**：里程核算、运费估算、载重校验、时效计算等
- **格式化工具**：运单解析、轨迹数据规整、报告模板渲染等
- **校验工具**：车牌/运单号校验、合规性检查、数据完整性校验等
- **查询工具**：路网状态、收费站信息、限行规则查询等

## 与其他目录的关系

| 目录 | 职责 |
|------|------|
| `methodology/` | 方法论与流程工具——定义「如何分析与交付」 |
| `workshop/skills/` | 精品 Skill——封装面向 Agent 的可执行能力 |
| `workshop/mcp/` | 精品 MCP——对接外部系统与数据源 |
| `workshop/tools/` | 精品 Agent 工具——公路 AI 场景下的可加载工具集 |

`tools` 与 `skills/` 区别在于：`skills/` 侧重端到端任务流程的编排与指令，`tools/` 侧重原子化、可组合的能力单元；Skill 可在执行过程中调用 `tools/` 中的工具完成具体计算与处理。

## 目录约定

每个工具建议以独立子目录组织，并至少包含：

```
<tool-name>/
├── README.md          # 工具说明、输入输出与使用方式
├── ...                # 工具实现、配置示例等
```

单个脚本且无依赖的小工具，也可直接以独立文件形式存放。

## 贡献说明

新增或更新工具时，请确保：

1. 说明输入输出、依赖环境与使用方式
2. 涉及外部系统调用时，注明鉴权方式与错误处理约定
3. 不提交密钥、证书等敏感信息；敏感配置使用环境变量或密钥管理
4. 遵循仓库 [贡献指南](../../../CONTRIBUTING.md) 提交 PR
