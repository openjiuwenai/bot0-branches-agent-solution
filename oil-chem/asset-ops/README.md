# asset-ops — 设备智能化运维场景资产

本目录用于存放 **油矿行业 Agent 解决方案** 中 **设备智能化运维场景** 的专属资产。

## 目录定位

`asset-ops` 聚焦设备智能化运维场景下的行业专属内容——当某些方法论、Skill、MCP 或 Agent 工具仅适用于设备智能化运维场景、不宜作为跨场景共享资产时，存放于本目录。

典型场景包括（但不限于）：

- **设备状态监测**：振动监测、油液分析、状态评估
- **预测性维护**：故障预测、剩余寿命（RUL）预测、维修决策
- **设备巡检**：智能巡检、缺陷识别、检修计划优化
- **资产全生命周期**：设备台账、备件管理、大修管理

## 与顶层目录的关系

| 目录 | 职责 |
|------|------|
| `methodology/` | 跨场景共享的方法论与流程工具 |
| `workshop/skills/` | 跨场景共享的精品 Skill |
| `workshop/mcp/` | 跨场景共享的精品 MCP |
| `workshop/tools/` | 跨场景共享的精品 Agent 工具 |
| `asset-ops/` | **设备智能化运维场景专属资产**（本目录） |

当资产可被多个场景复用时，应放入顶层 `methodology/` 或 `workshop/`；仅当强绑定设备智能化运维场景时，才放入本目录。

## 目录约定

本目录初期以 `README.md` 作为占位。后续可按需补充以下子目录：

```
asset-ops/
├── README.md
├── methodology/      # 可选：设备运维专属方法论
├── skills/           # 可选：设备运维专属 Skill
├── mcp/              # 可选：设备运维专属 MCP
└── tools/            # 可选：设备运维专属 Agent 工具
```

## 贡献说明

新增设备智能化运维场景专属资产时，请确保：

1. 说明该资产为何属于设备智能化运维场景专属、不适宜作为跨场景共享资产
2. 遵循顶层 `methodology/` 与 `workshop/` 中的目录约定与质量要求
3. 遵循仓库 [贡献指南](../../CONTRIBUTING.md) 提交 PR
