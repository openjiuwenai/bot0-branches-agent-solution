# 方法论（Methodology）

油气化工矿山钢铁行业 Agent 解决方案的跨场景共享资产区之一，沉淀可复用的方法论，为三类业务场景提供实施参考。

## 定位

| 维度 | 说明 |
| --- | --- |
| 资产形态 | 方法论文档、流程规范、实施指南等 |
| 使用方 | phm、smart-process、rd-intel 三类业务场景的实践者 |
| 与 workshop 的关系 | methodology 提供通用方法，workshop 提供按场景验证过的实践 |

## 目录约定

- 每份方法论一个子目录，命名体现场景或问题域
- 子目录内说明适用范围、使用前提与操作步骤
- 面向实施交付，避免纯理论描述
