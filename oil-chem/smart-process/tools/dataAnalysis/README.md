# 化工炼化物料平衡数据分析系统

基于 Web 服务的应用，用于导入化工炼化工艺的物料平衡数据（Excel 格式），自动进行行列转换、结构校验、收率分析与可视化。

## 功能概览

### 1. 数据导入
- 支持导入 Excel 格式的物料平衡原始数据
- 首次导入时自动识别字段结构，可手动调整字段类型（时间列 / 描述列 / 数值列）和排序
- 支持多 Sheet 选择导入
- 支持多种数据类型：2#加氢裂化、DCC催化裂解、舟山石化装置、罐表等，可自定义新增
- 支持天级 / 小时级数据导入，自动检测粒度
- 重复日期数据自动去重
- 支持清除已导入数据（按时间段、粒度或全部清除）
- 罐表数据特殊处理：序号为空的行跳过、合并单元格自动拆分填充

### 2. 收率趋势分析
- 总收率变化趋势图（出总/进总×100%），合理范围 98%-102%
- 可设置显示最大/最小值过滤异常数据
- 统计指标：平均收率、最低/最高收率、合格率
- 进出物料变化趋势图（可选总进出或按装置筛选）
- 总进出物料占比/收率饼图（进方向占比、出方向占比、出方向收率）
- 物料变化趋势（多选物料、时间段筛选、剔除日期）
- 稳定性分析：CV 评分、MAD 评分、滚动7日 CV 趋势线
- 物料平衡诊断：累积平衡曲线、切换事件时序、收率异常归因

### 3. 罐表分析
- 按罐号或物料筛选分析
- 液位变化趋势、罐量变化趋势
- 物料总量与累计平均值
- 各物料连续出现天数标注

### 4. 数据导出
- 可自定义导出时间段和保存位置
- 导出为 Excel 格式

## 技术栈

- **后端**：Python 3.10+ / FastAPI / pandas / openpyxl
- **前端**：原生 HTML / CSS / JavaScript（Jinja2 模板）
- **数据存储**：pickle 本地持久化

## 快速开始

### 环境要求

- Python 3.10 或更高版本

### 安装

```bash
# 进入项目目录
cd 19 data_analysis_glm

# 安装依赖
pip install -r requirements.txt
```

### 启动

```bash
python run.py
```

启动后会自动打开浏览器访问 `http://127.0.0.1:8765`。

如未自动打开，请手动访问该地址。

### 停止

在终端按 `Ctrl+C` 即可停止服务。

## 使用流程

### 第一步：导入数据

1. 打开 `http://127.0.0.1:8765` 进入导入页面
2. 从下拉菜单选择数据类型（如「2#加氢裂化」），或点击 `+` 新增数据类型
3. 选择粒度（天级 / 小时级）
4. 点击「选择文件」上传 Excel 文件
5. 首次导入时，在弹出窗口中确认字段结构（字段类型、排序）
6. 选择要导入的 Sheet
7. 导入完成后可预览数据

### 第二步：收率分析

1. 点击页面顶部「收率分析」或访问 `http://127.0.0.1:8765/analysis`
2. 在「分析数据源」区域选择数据源、数据模式、装置、时间范围
3. 点击「生成分析」按钮
4. 查看总收率趋势、进出物料趋势、占比/收率饼图
5. 在「物料变化趋势」区域选择物料、设置时间段进行深入分析

### 第三步：罐表分析

1. 访问 `http://127.0.0.1:8765/tank-analysis`
2. 选择罐号或物料进行液位、罐量趋势分析

## 数据格式说明

### 物料平衡数据

原始 Excel 数据经导入后自动转换为长表（tidy）格式：

| 时间 | 装置名称 | 侧线名称 | 进出类型 | 物料名称 | 数值 | 密度 |
|------|---------|---------|---------|---------|------|------|

- **时间列**：日期或日期时间
- **描述列**：装置、侧线、进出类型、物料名称等
- **数值列**：物料流量（bal 字段优先）
- **密度列**：气体物料按 数量×密度/1000 换算为质量

导入时字段名保持与原始数据一致，不自动修改。

### 罐表数据

罐表数据需包含序号、日期、罐号、物料、液位、罐量等字段。日期支持从右上角提取。合并单元格自动拆分。

## 常见问题

**Q: 导入时提示「无法识别时间列或数值列」？**
A: 检查原始数据是否包含日期列和数值列。首次导入时需在字段调整窗口中正确设置字段类型。

**Q: 收率数据不准确？**
A: 确认数值列选择正确（优先含 `bal` 的字段），检查是否有异常值需要剔除。

**Q: 如何清除已导入数据？**
A: 在导入页面选择数据类型和粒度后，点击「清除数据」按钮，可选按时间段或全部清除。

**Q: 支持哪些 Excel 格式？**
A: 支持 `.xlsx` 和 `.xls` 格式。
