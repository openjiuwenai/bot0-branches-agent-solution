# smart-process — 流程工业智能化场景资产

本目录用于存放 **油矿行业 Agent 解决方案** 中 **流程工业智能化场景** 的专属资产。

## 目录定位

`smart-process` 聚焦流程工业智能化场景下的行业专属内容——当某些方法论、Skill、MCP 或 Agent 工具仅适用于流程工业智能化场景、不宜作为跨场景共享资产时，存放于本目录。

典型场景包括（但不限于）：

- **炼化生产优化**：加工路线优化、收率预测、装置参数调优
- **过程控制**：先进过程控制（APC）、智能报警、回路优化
- **生产调度**：排产优化、计划调度、物料平衡
- **能效管理**：能耗优化、蒸汽系统优化、碳排放核算

## 与顶层目录的关系

| 目录 | 职责 |
|------|------|
| `methodology/` | 跨场景共享的方法论与流程工具 |
| `workshop/skills/` | 跨场景共享的精品 Skill |
| `workshop/mcp/` | 跨场景共享的精品 MCP |
| `workshop/tools/` | 跨场景共享的精品 Agent 工具 |
| `smart-process/` | **流程工业智能化场景专属资产**（本目录） |

当资产可被多个场景复用时，应放入顶层 `methodology/` 或 `workshop/`；仅当强绑定流程工业智能化场景时，才放入本目录。

## 目录约定

本目录以 `README.md` 说明场景定位，并按需组织以下子目录：

```
smart-process/
├── README.md
├── mcp/                                  # 流程工业专属 MCP 服务
│   └── refinery-route-optimizer/         # 炼厂加工路线优化器（收率预测 + 三路线效益对比）
├── methodology/      # 可选：流程工业专属方法论
├── skills/           # 可选：流程工业专属 Skill
└── tools/            # 可选：流程工业专属 Agent 工具
```

## 贡献说明

新增流程工业智能化场景专属资产时，请确保：

1. 说明该资产为何属于流程工业智能化场景专属、不适宜作为跨场景共享资产
2. 遵循顶层 `methodology/` 与 `workshop/` 中的目录约定与质量要求
3. 遵循仓库 [贡献指南](../../CONTRIBUTING.md) 提交 PR
