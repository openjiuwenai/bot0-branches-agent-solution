# 求解编排流程指导

> **用途**：本文档供 Agent 平台导入为知识库，指导 Agent 如何按正确顺序调用 MCP 工具完成炼化求解全流程。

## 全链路编排（6 步）

```
① 数据准备 → ② 组合枚举 → ③ 物理计算 → ④ 可行性判断 → ⑤ 选优 → ⑥ 结果渲染
```

### ① 数据准备

**目的**：预加载价格、成本、配比等引用数据。

| MCP 工具 | 作用 |
|----------|------|
| `get_prices(month)` | 查询物料价格 |
| `get_yields(side_line_id, crude_type)` | 查询收率 |
| `list_units()` | 查询装置列表 |
| `list_tanks()` | 查询罐容信息 |
| `preload_reference_data(batches, plan_month)` | 一次性预加载价格+成本+配比 |

**注意**：
- 价格有"双月口径"：选优用上月价，核算用本月价
- `preload_reference_data` 一次调用替代多次单查，推荐使用

### ② 组合枚举

**目的**：根据排产计划，枚举减一线阀门切换的所有可能组合。

这一步由 MCP-01/02 内部完成，不需要单独调用。如果需要独立枚举，使用 `optimize_combinations`（MCP-06）。

### ③ 物理计算

**目的**：对每个组合，计算 BFS 拓扑遍历后的装置进出料流量、利用率、罐容检测。

| MCP 工具 | 作用 |
|----------|------|
| `calculate_batch_physical`（MCP-03） | 单批次物理计算 |
| `calculate_batch_full`（MCP-04） | 单批次完整计算（物理+经济） |
| `evaluate_valve_combination`（MCP-05） | 单组合评估 |
| `optimize_combinations`（MCP-06） | 全组合遍历+物理计算（推荐，一次调完） |

**关键约束**：
- **批量物理计算必须一次调完**，不能逐组合调 MCP-05（组合数可达 8~16 个，逐个调太慢）
- MCP-06 内部已实现缓存复用（PASS 1 物理结果供后续 PASS 复用）
- MCP-06 返回的 `combination_results` 是后续 MCP-15/16 的输入

### ④ 可行性判断（定制点 A）

**目的**：按定制规则判定每个组合是否可行。

| MCP 工具 | 作用 |
|----------|------|
| `assess_feasibility`（MCP-15） | 参数化可行性判断 |

**定制方式**：Agent 根据用户意图组装 `rules` 参数（详见《炼化可行性规则字典》）。

### ⑤ 选优（定制点 B）

**目的**：按定制策略从可行组合中选取最优。

| MCP 工具 | 作用 |
|----------|------|
| `select_optimal`（MCP-16） | 参数化选优 |

**定制方式**：Agent 根据用户意图组装 `strategy` 参数（详见《选优策略指导》）。

### ⑥ 结果渲染

| MCP 工具 | 作用 |
|----------|------|
| `aggregate_batch_economics`（MCP-08） | 聚合经济效益 |
| `render_economic_summary`（MCP-09） | 生成文字说明 |
| `build_economic_breakdown`（MCP-10） | 结构化拆解 |
| `build_flow_diagram`（MCP-12） | 流程图数据 |
| `analyze_jian1_switch`（MCP-11） | 减一线切换分析 |

## 两种调用路径

### 路径 A：一站式（适合简单场景）

直接调用 MCP-01（`solve_refinery_plan`），在参数中传入 `feasibility_rules` 和 `selection_strategy`：

```
solve_refinery_plan(
    plan_month="2026-07",
    production_plans_input=[...],
    monthly_crude_input=80000,
    feasibility_rules={"max_load_rate": 95.0},
    selection_strategy={"objective": "risk_averse"}
)
```

MCP-01 内部自动完成 ①~⑥ 全部步骤。**不传 rules/strategy 时使用默认规则**。

### 路径 B：分步编排（适合复杂场景）

Agent 逐步调用 MCP 工具，中间插入自定义逻辑：

```
1. preload_reference_data(batches, "2026-07")
2. optimize_combinations(batches, combinations, ...) → combination_results
3. [Agent 自定义逻辑：分析组合特征]
4. assess_feasibility(combination_results, {"max_load_rate": 95.0})
5. [Agent 自定义逻辑：调整规则]
6. select_optimal(combination_results, {"objective": "multi_objective", ...})
7. aggregate_batch_economics(optimal_explanations, ...)
8. render_economic_summary(agg, ...)
```

## 双价格月口径（重要领域知识）

| 阶段 | 价格月 | 说明 |
|------|--------|------|
| 选优（挑组合） | plan_month 的上个月 | 用上月价格/成本评估所有组合，挑利润最高 |
| 核算（算效益） | plan_month 本月 | 选中组合用本月价格/成本全量重算，核实实际效益 |
| 排产 | plan_month | 排产始终用本月 |

**Agent 不需要手动处理双月口径**：MCP-01 内部自动推导，MCP-06 通过 `select_month` / `final_month` 参数控制。
