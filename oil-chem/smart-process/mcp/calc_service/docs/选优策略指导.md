# 选优策略指导

> **用途**：本文档供 Agent 平台导入为知识库，指导 Agent 如何根据用户意图组装 `select_optimal`（MCP-16）的 `strategy` 参数。

## MCP-16 工具签名

```
select_optimal(combination_results: list, strategy: dict = None) -> dict
```

- `combination_results`：已经过 MCP-15（assess_feasibility）判定的组合列表
- `strategy`：选优策略 dict，不传时使用默认策略（max revenue）

## 策略字段定义

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `objective` | str | "revenue" | 选优目标模式（见下表） |
| `weights` | dict | `{"revenue": 1.0}` | multi_objective 模式下的权重配置 |
| `prefer_near_feasible` | bool | True | 无完全可行方案时是否接受接近可行 |
| `penalty_factor` | float | 1.0 | risk_averse 模式的超容惩罚系数 |
| `min_revenue` | float | 0.0 | 最低收益门槛，低于此值不参与选优 |

## 选优目标模式

| objective | 说明 | 适合场景 |
|-----------|------|---------|
| `revenue` | 最大收益（默认） | 追求利润最大化 |
| `feasibility_margin` | 最大可行性边际 | 优先选最安全/负荷最低的方案 |
| `risk_averse` | 风险规避 | 综合收益与超容惩罚，平衡利润与风险 |
| `multi_objective` | 多目标加权 | 需同时兼顾多个目标 |

## multi_objective 权重配置

| 权重字段 | 说明 | 单位 |
|----------|------|------|
| `revenue` | 总收益权重 | 万元 |
| `feasibility_margin` | 可行性边际权重 | 百分比（负荷余量） |
| `hangmei_output` | 航煤产出权重 | 吨 |

权重值需归一化后加权求和。归一化在所有候选组合间进行（max-min 归一化到 [0,1]）。

## 用户意图 → strategy 映射

| 用户表述 | strategy_json |
|----------|--------------|
| "利润最大化" | `{"objective": "revenue"}` |
| "选最安全的方案" | `{"objective": "feasibility_margin"}` |
| "兼顾利润和安全" | `{"objective": "risk_averse", "penalty_factor": 1.0}` |
| "更看重安全" | `{"objective": "risk_averse", "penalty_factor": 3.0}` |
| "利润和航煤保供都要" | `{"objective": "multi_objective", "weights": {"revenue": 0.6, "hangmei_output": 0.4}}` |
| "利润/安全/航煤三者平衡" | `{"objective": "multi_objective", "weights": {"revenue": 0.5, "feasibility_margin": 0.3, "hangmei_output": 0.2}}` |
| "不要接近可行方案" | `{"prefer_near_feasible": false}` |
| "收益低于100万不要" | `{"min_revenue": 1000000}` |

## 选优优先级

```
1. 完全可行组合中按 objective 评分选最优
2. 若无可行组合，在接近可行组合中选最优（prefer_near_feasible=True 时）
3. 若均无，按超容惩罚乘积选最轻组合（fallback）
4. prefer_near_feasible=False 时，步骤 2/3 不执行，返回 None
```

## 组合调用示例

```
场景：用户要"兼顾利润和安全，航煤保供3000吨"

1. MCP-06: optimize_combinations → combination_results
2. MCP-15: assess_feasibility(combination_results, {"min_hangmei_output": 3000})
3. MCP-16: select_optimal(combination_results, {
     "objective": "multi_objective",
     "weights": {"revenue": 0.5, "feasibility_margin": 0.3, "hangmei_output": 0.2}
   })
```
