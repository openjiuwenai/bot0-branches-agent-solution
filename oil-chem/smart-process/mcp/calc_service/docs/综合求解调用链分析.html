5. 调用次数公式

设 B = 批次数，C = 组合数（通常 C = 2^(B-1)），D = 装置数。

阶段函数调用次数说明
PASS 1 选优evaluate_combinationC每个组合评估一次（summary_only=True，上月价）
PASS 1 内部calculate_physicalC × B → ≤ 2BP0 物理缓存：同 (batch_id, mode, in_hangmei_window) 只算一次
PASS 1 内部generate_explanationC × B → ≤ 2BP0 经济参数匹配时复用缓存 explanation
PASS 1 内部_compute_combo_hangmeiC → 1P1 航煤预计算缓存：同 (batch_id, mode) 只算一次
PASS 3 核算evaluate_combination1最优组合全量重算（summary_only=False，本月价）
PASS 4 对比recompute_combination_economicsC - 1P2 复用 PASS 1 物理计算。最优组合复用 PASS 3 (P5)
PASS 4 内部generate_explanation(C-1) × B → ≤ 2BP0 跨组合经济缓存复用
PASS 4 航煤_compute_combo_hangmeiC - 1P4 航煤搜索依赖价格，用本月价重跑
总 calculate_physical 调用 ≈ 3B | 总 generate_explanation 调用 ≈ 5B | 无优化时 4CB（C=8,B=4时 128次→优化后≈20次）

def optimize_combinations(batches, combinations, custom_crude_costs,

calculate_physical() — 纯物理计算（不含经济计算/价格参数），Phase 4 拆分为 7 子函数：

def calculate_physical(scenario, input_amount, yield_mode, logger=None,
        total_input_amount=None, days=1, hangmei_mode=False,
        hangmei_m_days=0, day_index=0, shutdown_intervals=None,
        feed_ratios: Dict = None) -> Tuple[bool, dict]

执行 BFS 拓扑遍历、流量计算、停工缩减、装置利用率构建，返回物理字段 result_dict（不含 explanation）。

子函数说明
_build_topology(scenario) BFS 拓扑排序（每次重算，<0.5ms，无需缓存）。返回 device_order 列表
_init_special_vars(yield_mode, input_amount, scenario) 计算 jian1 理论总量并设置特殊变量 X/Y。X_ZERO: X=0, Y=jian1_total；Y_ZERO: X=jian1_total, Y=0
_resolve_eff_input(scenario, dev_id, dev_input, ...) 按 max_yr main_feed + target_product_id 计算总进料量。连接主料量 / max_yr main_feed.yield_rate

_fix_cross_edges(scenario, device_order, ...) 修正 BFS 拓扑序交叉边：从完整 connection_flows 重算 device_inputs 和 total_feeds
_apply_shutdown_scaling(...) 停工按小时比例缩减：装置产出/连接 flow 按非停工时长比例缩减。进料罐照常接收 CDU 来料
