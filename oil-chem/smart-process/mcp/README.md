# mcp — 流程工业智能化精品 MCP

本目录用于存放 **油气化工矿山钢铁行业 Agent 解决方案** 中 **流程工业智能化场景** 的精品 MCP（Model Context Protocol）服务资产。

## 目录定位

`mcp` 聚焦「连什么、调什么」——提供与流程工业智能化场景相关的系统、数据源及第三方服务对接的标准化 MCP 实现，使 Agent 能够安全、可控地访问外部能力。

典型能力包括（但不限于）：

- **数据查询**：原油/原料性质、装置参数、收率与能耗指标、生产监控数据等
- **业务系统对接**：生产管理系统（MES）、过程控制系统（DCS/APC）、计划调度系统、工单等（在授权范围内）
- **工具集成**：工艺计算引擎、文档解析、身份核验等

## 与其他目录的关系

| 目录 | 职责 |
|------|------|
| `methodology/` | 方法论与流程工具——定义「如何分析与交付」 |
| `workshop/skills/` | 跨场景共享的精品 Skill——封装面向 Agent 的可执行能力 |
| `workshop/mcp/` | 跨场景共享的精品 MCP——对接外部系统与数据源 |
| `workshop/tools/` | 跨场景共享的精品 Agent 工具 |
| `smart-process/` | **流程工业智能化场景专属资产**（本目录） |

MCP 为 Skill、Tools 与 Agent 运行时提供「手脚」；调用逻辑与合规约束应配合 `methodology/` 与 `skills/` 中的规范使用。当资产可被多个场景复用时，应放入顶层 `workshop/`；仅当强绑定流程工业智能化场景时，才放入本目录。

## 目录约定

每个 MCP 服务建议以独立子目录组织，典型结构如下：

```
<mcp-name>/
├── README.md          # 服务说明、配置方式与工具清单
├── ...                # 服务端实现、配置示例等
```

## 贡献说明

新增或更新 MCP 服务时，请确保：

1. 说明所需鉴权方式、环境变量与部署依赖
2. 明确数据范围、调用频率与错误处理约定
3. 不提交密钥、证书等敏感信息；敏感配置使用环境变量或密钥管理
4. 遵循仓库 [贡献指南](../../../CONTRIBUTING.md) 提交 PR
