# 研发智能化场景（rd-intel）

油气化工矿山钢铁行业 Agent 解决方案的业务场景之一，面向实验研发、模拟计算、知识产权、研发管理等研发智能化业务。

## 典型子场景

| 子场景 | 说明 |
| --- | --- |
| 配方与催化剂研发 | 配方设计、催化剂筛选与性能预测 |
| 实验数据管理 | 实验设计（DOE）、实验数据采集与分析、LIMS 对接 |
| 模拟计算 | 分子模拟、流程模拟等计算任务的辅助建模与结果分析 |
| 知识产权 | 专利检索、技术情报分析、侵权风险排查 |
| 科研知识管理 | 文献与报告知识库、研发问答助手 |
| 研发项目管理 | 项目立项、进度与资源管理、成果沉淀 |

## 资产形态

| 子目录 | 资产类型 | 说明 |
| --- | --- | --- |
| mcp/ | MCP 服务 | 场景对外提供能力的标准协议入口 |
| skills/ | Skill | 可被 Agent 直接调用的业务级操作单元 |
| tools/ | 工具 / 业务系统 | 可独立运行、解决具体业务问题的能力单元 |

## 与其他目录的关系

| 目录 | 定位 |
| --- | --- |
| methodology/ | 跨场景方法论，是本场景资产的方法论输入 |
| workshop/ | 跨场景最佳实践，是本场景资产的实践参照 |

## 目录结构说明

```
rd-intel/
├── mcp/        # 场景级 MCP 服务
├── skills/     # 场景级 Skill
└── tools/      # 场景级工具与业务系统
```
