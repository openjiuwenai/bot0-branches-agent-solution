# rd-intel — 研发智能化场景资产

本目录用于存放 **油矿行业 Agent 解决方案** 中 **研发智能化场景** 的专属资产。

## 目录定位

`rd-intel` 聚焦研发智能化场景下的行业专属内容——当某些方法论、Skill、MCP 或 Agent 工具仅适用于研发智能化场景、不宜作为跨场景共享资产时，存放于本目录。

典型场景包括（但不限于）：

- **实验研发**：配方设计、实验方案优化、实验结果分析
- **模拟计算**：工艺模拟、分子模拟、物性预测
- **知识产权**：专利检索、技术情报、文献分析
- **研发管理**：项目立项、进度跟踪、成果转化

## 与顶层目录的关系

| 目录 | 职责 |
|------|------|
| `methodology/` | 跨场景共享的方法论与流程工具 |
| `workshop/skills/` | 跨场景共享的精品 Skill |
| `workshop/mcp/` | 跨场景共享的精品 MCP |
| `workshop/tools/` | 跨场景共享的精品 Agent 工具 |
| `rd-intel/` | **研发智能化场景专属资产**（本目录） |

当资产可被多个场景复用时，应放入顶层 `methodology/` 或 `workshop/`；仅当强绑定研发智能化场景时，才放入本目录。

## 目录约定

本目录以 `README.md` 说明场景定位，并按需组织以下子目录：

```
rd-intel/
├── README.md
├── mcp/              # 研发专属 MCP 服务（按需补充）
├── methodology/      # 可选：研发专属方法论
├── skills/           # 可选：研发专属 Skill
└── tools/            # 可选：研发专属 Agent 工具
```

## 贡献说明

新增研发智能化场景专属资产时，请确保：

1. 说明该资产为何属于研发智能化场景专属、不适宜作为跨场景共享资产
2. 遵循顶层 `methodology/` 与 `workshop/` 中的目录约定与质量要求
3. 遵循仓库 [贡献指南](../../CONTRIBUTING.md) 提交 PR
