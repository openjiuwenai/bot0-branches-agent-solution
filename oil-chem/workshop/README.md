# workshop — 油气化工矿山钢铁工作坊

本目录用于汇聚 **油气化工矿山钢铁行业 Agent 解决方案** 的精品 Skill、精品 MCP 与精品 Agent 工具资产，是 Agent 运行时可直接加载与调用的能力中心。

## 目录结构

| 目录 | 职责 |
|------|------|
| `skills/` | 精品 Skill——封装面向 Agent 的可执行任务能力 |
| `mcp/` | 精品 MCP——对接外部系统与数据源的服务实现 |
| `tools/` | 精品 Agent 工具——油气化工矿山钢铁场景下的可加载工具集 |

## 目录定位

`workshop` 聚焦「能做什么、连什么、用什么」——将油气化工矿山钢铁领域的专业能力、外部连接与可加载工具整合在一起，便于 Agent 在运行时按需加载：

- `skills/` 封装端到端的可执行业务能力
- `mcp/` 提供与行业系统、数据源及第三方服务对接的标准化实现
- `tools/` 提供油气化工矿山钢铁场景下的原子化、可组合的精品 Agent 工具

新增或更新 Skill / MCP / Tools 资产时，请确保：

1. 说明所需鉴权方式、环境变量与部署依赖
2. 明确能力边界、调用频率与错误处理约定
3. 不提交密钥、证书等敏感信息；敏感配置使用环境变量或密钥管理
4. 遵循仓库 [贡献指南](../../CONTRIBUTING.md) 提交 PR
