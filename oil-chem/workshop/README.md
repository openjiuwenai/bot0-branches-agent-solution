# 工作台与最佳实践（Workshop）

油气化工矿山钢铁行业 Agent 解决方案的跨场景共享资产区之一，沉淀各业务场景验证过的可复用做法，供三类业务场景参照落地。

## 资产形态

| 子目录 | 资产类型 | 说明 |
| --- | --- | --- |
| mcp/ | MCP 服务 | 对外提供能力的标准协议入口 |
| skills/ | Skill | 可被 Agent 直接调用的业务级操作单元 |
| tools/ | 工具 / 业务系统 | 可独立运行、解决具体业务问题的能力单元 |

## 与其他目录的关系

| 目录 | 定位 |
| --- | --- |
| methodology/ | 跨场景方法论，是本目录实践沉淀的方法论输入 |
| phm/、smart-process/、rd-intel/ | 三类业务场景，复用本目录的最佳实践 |

## 目录结构说明

```
workshop/
├── mcp/        # MCP 服务
├── skills/     # Skill
└── tools/      # 工具与业务系统
```
