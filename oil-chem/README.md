# 油气化工矿山钢铁行业 Agent 解决方案（oil-chem）

本目录是 agent-solution 仓库中油气化工矿山钢铁行业的核心资产区，由「跨场景共享资产」与「场景专属资产」两部分组成。

## 跨场景共享资产

按能力类型划分为以下子目录，存放可被多个场景复用的资产：

| 目录 | 说明 |
|------|------|
| `methodology/` | 方法论与流程工具——分析框架、模板、辅助脚本等 |
| `workshop/` | 工作台与最佳实践——沉淀各场景验证过的 Skill、MCP 服务与工具 |

两者协同：methodology 定义规范与流程，workshop 封装 Agent 能力、外部连接与可加载工具。

## 场景专属资产

按智能化场景划分，仅存放强绑定该场景、不宜跨场景共享的资产：

| 目录 | 说明 |
|------|------|
| `smart-process/` | 流程工业智能化场景——炼化生产优化、过程控制、生产调度、能效管理等 |
| `phm/` | 设备智能化运维场景（Prognostics & Health Management，PHM）——设备状态监测、预测性维护、智能巡检、资产全生命周期等 |
| `rd-intel/` | 研发智能化场景——实验研发、模拟计算、知识产权、研发管理等 |

资产归属原则：可被多个场景复用的资产放入顶层 `methodology/` 或 `workshop/`；仅当强绑定单一场景时，才放入对应场景目录。
