# 设备智能化运维场景（phm）

油气化工矿山钢铁行业 Agent 解决方案的业务场景之一。设备智能化运维（Prognostics & Health Management，PHM）面向设备状态监测、预测性维护、智能巡检、资产全生命周期管理等方向。

## 典型子场景

围绕 PHM「监测—诊断—预测—决策」能力链路展开：

| 子场景 | 说明 |
| --- | --- |
| 数据采集与处理 | 振动、温度、压力、工艺参数等多源数据采集、清洗与特征提取 |
| 状态监测 | 机泵、压缩机等关键设备运行状态实时监视与越限告警 |
| 故障诊断 | 异常检测、故障模式识别与根因定位 |
| 故障预测 | 设备健康度评估、退化趋势分析、剩余使用寿命（RUL）预测 |
| 维修决策支持 | 维修策略推荐、检修计划排程、备件需求预测 |
| 智能巡检 | 巡检路线管理，基于图像/声音识别跑冒滴漏、仪表读数与现场异常 |
| 资产全生命周期管理 | 设备台账、可靠性分析（RCM/RCA）、更新与报废决策 |

## 资产形态

| 子目录 | 资产类型 | 说明 |
| --- | --- | --- |
| mcp/ | MCP 服务 | 场景对外提供能力的标准协议入口 |
| skills/ | Skill | 可被 Agent 直接调用的业务级操作单元 |
| tools/ | 工具 / 业务系统 | 可独立运行、解决具体业务问题的能力单元 |

## 与其他目录的关系

| 目录 | 定位 |
| --- | --- |
| methodology/ | 跨场景方法论，是本场景资产的方法论输入 |
| workshop/ | 跨场景最佳实践，是本场景资产的实践参照 |
