# 电力行业 Agent 解决方案（electric）

本目录是 agent-solution 仓库中电力行业的核心资产区，由「分队场景专属资产」与「跨场景共享资产」两部分组成。

## 分队场景专属资产

按分队划分，下面挂对应分队的目录，仅存放强绑定的分队场景、不宜跨场景共享的资产：

| 目录 | 说明                                  |
|------|-------------------------------------|
| `stateGrid/` | 国网分队资产                              |
| `southernGrid/` | 南网分队资产                              |
| `generatePower/` | 发电分队资产                              |
| `workshop/` | 工作台与最佳实践——沉淀各场景验证过的 Skill、MCP 服务与工具 |

资产归属原则：可被多个场景复用的资产放入顶层 `methodology/` 或 `workshop/`；仅当强绑定单一场景时，才放入对应场景目录。

## 跨场景共享资产

按能力类型划分为以下子目录，存放可被多个场景复用的资产：

| 目录 | 说明                              |
|------|---------------------------------|
| `workshop/` | 沉淀各场景验证过的可公共复用的 Skill、MCP 服务与工具 |

workshop 封装 Agent 能力、外部连接与可加载工具。
